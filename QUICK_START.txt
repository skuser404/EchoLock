1. REGISTRATION:
   → Click "Register New User"
   → Enter username: "demo_user"
   → Set PIN: "1234"
   → Type PIN 5 times naturally
   → Click "Complete Registration"

2. SUCCESSFUL LOGIN:
   → Go to Login
   → Enter same username and PIN
   → Type at normal speed
   → Result: "Access Granted" (85-95% match)

3. FAILED LOGIN:
   → Ask someone else to try
   → OR type very fast/slow
   → Result: "Access Denied" (<50% match)

4. OTP FLOW:
   → Type slightly differently
   → Result: "OTP Required" (50-80% match)
   → Enter displayed OTP
   → Access granted
